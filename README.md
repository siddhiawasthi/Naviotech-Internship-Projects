# Beginner Machine Learning Projects
Two beginner-friendly projects based on the assignment spreadsheet:
1. **Telecom Churn Prediction** — classification.
2. **Bank Customer Intelligence and Customer Retention Analytics** — customer analytics and classification.

Each folder contains a CSV dataset, Python scripts, requirements, README and project report. The `outputs/` and `models/` folders are created when scripts are run.

## Run
Open a terminal in the individual project folder, create a virtual environment, install `requirements.txt`, and follow that project's README.

## Data notice
Both datasets are synthetic sample records created for learning. They are not real telecom or bank customer data.
